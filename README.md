# 💕 CharacterMeet - 소개팅앱

2인 4시간으로 구현한 빠른 프로토타입 소개팅앱 서비스입니다.

## 🚀 주요 기능

### 1. MBTI 설문조사
- 간단한 5개 질문으로 빠른 성격 분석
- 실시간 진행률 표시
- 직관적인 UI/UX

### 2. 연애 캐릭터 시스템
- 8가지 MBTI 유형별 연애 캐릭터
- 각 캐릭터의 성격 특성과 설명
- 시각적으로 매력적인 캐릭터 카드

### 3. 매칭 시스템
- 호환성 기반 매칭 알고리즘
- 상위 3명의 매칭 결과 제공
- 호환성 점수 표시

## 🛠️ 기술 스택

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **디자인**: 반응형 웹 디자인, 그라데이션 UI
- **데이터**: JSON 기반 로컬 데이터 관리

## 🎯 2인 4시간 개발 전략

### 역할 분담
- **개발자 A**: UI/UX 디자인 + MBTI 설문조사 구현
- **개발자 B**: 매칭 알고리즘 + 데이터 관리 + 웹페이지 통합

### 시간 배분
1. **1시간**: 프로젝트 설정 + 기본 UI 구조
2. **1.5시간**: MBTI 설문조사 + 캐릭터 시스템
3. **1시간**: 매칭 알고리즘 + 데이터 연동
4. **0.5시간**: 웹페이지 + 최종 통합
